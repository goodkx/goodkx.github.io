怎么拿到令牌？（两种方式）
方式 A：本机已登录 gh（最快）
  1. 在这个仓库的电脑上打开 PowerShell，运行 gh auth token | Set-Clipboard
  2. 回到本页，令牌直接在剪贴板里，粘到上面输入框 → 保存并测试
方式 B：新建细粒度令牌（更安全，只给这一个仓库）
  1. 在能打开 github.com 的网络下访问 github.com/settings/personal-access-tokens/new
  2. Repository access 选 Only select repositories → goodkx.github.io
  3. Permissions → Repository permissions → Contents: Read and write（其余全留 No access）
  4. 生成后复制 github_pat_… 粘到上面
