PART 1 / 计算机网络 · 第 4 章

网络层

它不关心你用什么网线、连哪个 Wi-Fi。
它只干一件事：把 IP 数据报，从源主机一路送到目的主机。

逻辑通信 尽力而为 无连接 路由 + 转发
4.1 概述

网络层：一家只承诺「尽力」的快递公司

NET / 01

📦 它只做两件事

  • 转发（Forwarding）：路由器收到分组，查表、从哪个口出去 —— 局部动作，纳秒级
  • 路由选择（Routing）：全网一起算，哪条路最合适 —— 全局动作，秒级

🪄 什么叫「逻辑通信」？

从传输层往下看，源主机和目的主机好像一条直连的线；
实际上中间要穿过很多路由器、很多种链路（光纤、Wi-Fi、4G）。
网络层把这堆复杂细节全部藏起来，只露出一个「IP 地址」。

⚠️

「尽力而为」= 不保证。不保证送到、不保证不重复、不保证按序。可靠性交给运输层 TCP 负责。

4.1 两种服务

寄快递：一次一单 vs 打专线电话

NET / 02

数据报服务

IP 采用
  • 每个分组独立选路，各走各的
  • 可能乱序、重复、丢失
  • 网络不维护连接状态，简单、便宜、能扛规模
  • 可靠性交给端系统（TCP）
  • 代表：IP
VS

虚电路服务

早期网络
  • 通信前先建立连接，分配一条路径
  • 所有分组走同一条路，按序到达
  • 网络负责可靠性，路由器要记连接状态
  • 节点故障影响大，扩展性差
  • 代表：X.25 帧中继 ATM

🤔 为什么互联网最后选了数据报？

因为互联网要连接无数异构网络：有的可靠、有的不可靠。把可靠性统一压到端系统，网络层就能做得又简单又快，出了故障也只影响局部。

📝 一句话答题模板

「IP 层提供无连接、不可靠的数据报服务；可靠性由运输层保证。」
考到「网络层提供什么服务」就写这句。

4.2 IP 地址

IP 地址 = 32 位二进制门牌号

NET / 03

写成「点分十进制」最好看

4 组 × 8 位
192.168.1.10
11000000 10101000 00000001 00001010

每个数字 0~255，四个数字拼起来就是 32 位

结构

网络号 + 主机号

网络号 net-id标志「在哪个网络」
主机号 host-id标志「网络里的哪台机」
🏠

IP 地址不是「哪台电脑」的永久名字，而是这块网卡在这个网络里的位置 —— 换网络就得换地址。

🔢 换算不用怕

只要记住：
11111111 = 255
11000000 = 128 + 64 = 192
10101000 = 128 + 32 + 8 = 168

🧠 记忆钩子

把 IP 想成「小区名 + 门牌号」：
网络号告诉你哪个小区，主机号告诉你几零几。

4.2.2 分类编址

五类地址：看第一个数字就能认出来

NET / 04

🎯 秒判口诀

看第一段数字：
1~126 → A，128~191 → B，192~223 → C，224~239 → D。
注意 0 和 127 是特殊地址，不分配给主机。

📐 主机数怎么算

主机号有 n 位 → 可分配 2ⁿ − 2 个。
减 2：主机号全 0 是「网络地址」，全 1 是「广播地址」，都不能给主机用。

4.2.3 特殊地址

这些地址，考试最爱挖坑

NET / 05
全 0

0.0.0.0

本网络、本主机。DHCP 请求时源地址就填它：“我还没地址，谁来给我一个？”

环回

127.0.0.1

本机环回地址，数据不出网卡。ping 它通，说明本机 TCP/IP 协议栈正常。

广播

255.255.255.255

受限广播地址，只在本局域网内发，路由器不转发。

🔒 私有地址：家里、公司里随便用

地址块范围数量

🎭 网络地址 vs 广播地址

以 192.168.1.0/24 为例：
192.168.1.0 → 网络地址（主机号全 0）
192.168.1.255 → 广播地址（主机号全 1）
可用主机：192.168.1.1 ~ 192.168.1.254，共 254 个

🧠

记忆：全 0 是「这个班」，全 1 是「全班喊话」，中间的才是具体某个人。

4.2.4 子网划分

把一个大班级，隔成几个小班

NET / 06

✂️ 三级结构：网络号 → 子网号 → 主机号

网络号原封不动
子网号从主机号借来的
主机号剩下的位数

借 n 位做子网号 → 能分 2ⁿ 个子网；
剩下 m 位做主机号 → 每个子网 2ᵐ − 2 台主机。

🎭 子网掩码怎么用

规则：网络号 + 子网号 = 1，主机号 = 0。
IP 与掩码做按位与，得到的就是网络地址。

192.168.10.130AND255.255.255.192=192.168.10.128

📏 常见掩码速查

前缀掩码每子网主机
/25.128126
/26.19262
/27.22430
/28.24014
/30.2522（点对点链路）
💡

看到 255.255.255.224，立刻反应：/27、块大小 32。

手把手例题

把 192.168.10.0/24 切成 4 个 /26

NET / 07

Step 1 · 借几位？

要 4 个子网 → 2ⁿ ≥ 4 → n = 2
原来 /24，借 2 位 → 新前缀 /26，掩码 255.255.255.192。

Step 2 · 块多大？

主机位剩 6 位 → 每块 2⁶ = 64 个地址。
起点：0、64、128、192。

Step 3 · 可用范围

每块去掉头（网络地址）和尾（广播地址），中间 62 个可用。

子网网络地址可用主机范围广播地址
子网 0192.168.10.0.1 ~ .62.63

子网 2192.168.10.128.129 ~ .190.191
子网 3192.168.10.192.193 ~ .254.255
✍️

答题时先写「借 2 位、块大小 64」，再列表。改卷老师最喜欢这种有过程的答案。

4.3 无分类编址

CIDR：地址后面加个「/n」就完事

NET / 08

🎯 核心思想：不再分 A/B/C

写成 a.b.c.d/n，n 就是网络前缀长度。
例如 200.100.1.0/24 表示前 24 位是网络前缀，剩 8 位给主机。
地址块大小 = 2^(32−n)

🧩 路由聚合（超网）

把多条前缀相同的路由合成一条，减小路由表。

200.100.0.0/24 200.100.1.0/24 200.100.2.0/24 200.100.3.0/24

前 22 位相同 → 聚合成 200.100.0.0/22

🏆 最长前缀匹配

路由表里有多条都能匹配时，选前缀最长（最具体）的那条。

200.100.0.0/22→ 出口 A
200.100.1.0/24→ 出口 B（胜出）
0.0.0.0/0→ 默认路由

🧮 块大小速算

块大小 = 2(32−n)。/24 → 256；/26 → 64；/28 → 16；/30 → 4。子网起点一定是块大小的整数倍。

🏃

「最长前缀匹配」就是最具体的优先。目标地址 200.100.1.77 同时匹配 /22 和 /24，选 /24。

4.2.4 ARP

ARP：拿着门牌号，问出身份证号

NET / 09

🆔 先分清两种地址

IP 地址

逻辑地址，32 位，可变。
相当于「收货地址」。

MAC 地址

物理地址，48 位，烧在网卡里。
相当于「身份证号」。

📢 ARP 的工作方式

  • 先查 ARP 高速缓存，有就直接用
  • 没有 → 在本局域网广播 ARP 请求
  • 目标主机单播回复自己的 MAC
  • 结果写入缓存，下次不用再问

🔀 跨网段时，MAC 会变、IP 不变

链路源 MAC目的 MAC
主机 → 路由器主机网卡路由器接口
路由器 → 主机路由器接口目标主机

IP 数据报的源/目的 IP 始终不变；MAC 帧每过一跳就换一次「信封」。

📮

IP 是最终收件人，MAC 是这一站送快递的小哥。包裹一路转手，收件人名字不会改。

4.2.5 数据报格式

IP 数据报首部：一张 20 字节的快递单

NET / 10
版本4 位
首部长度4 位
区分服务8 位
总长度16 位
标识 Identification16 位
标志3 位
片偏移13 位
生存时间 TTL8 位
协议8 位
首部检验和16 位
源 IP 地址32 位
目的 IP 地址32 位

固定部分 20 字节；可选字段最多 40 字节，总首部最长 60 字节。

首部长度

单位是 4 字节。最小值 5（20 字节），最大值 15（60 字节）。

总长度

单位是 字节，最大 65535。= 首部 + 数据。

TTL 生存时间

每过一个路由器减 1，减到 0 就丢弃并回 ICMP 超时。防止分组在环里打转。

协议字段

TCP=6，UDP=17，ICMP=1，OSPF=89 —— 告诉目的主机「数据交给谁」。

🔍

首部检验和只校验首部，不校验数据；每经过一个路由器都要重新计算（因为 TTL 变了）。

🚩

标志位：DF=1 禁止分片；MF=1 表示后面还有片；MF=0 表示这是最后一片。

重点计算

分片：过不了 MTU，就把包裹拆开

NET / 11

📦 为什么要分片

每种链路有最大帧长，能携带的 IP 数据报上限叫 MTU（以太网通常 1500 字节）。超了就得拆。

🧩 三个字段配合

  • 标识：同一原始数据报的片，标识相同
  • MF：还有后续片 = 1，最后一片 = 0
  • 片偏移：本片数据在原始数据中的位置 ÷ 8

注意：片偏移的单位是 8 字节，所以每片数据长度必须是 8 的倍数（最后一片除外）。

⚠️

分片可以发生在源主机或中间路由器；但重组只在目的主机做。

✍️ 例题：4000 字节数据报过 1500 MTU

首部 20 字节 → 每片最多携带 1500 − 20 = 1480 字节数据。

片数据长度片偏移MF
第 1 片148001
第 2 片14801851
第 3 片10203700

偏移算法：1480 ÷ 8 = 185；第二片起点 1480 → 1480 ÷ 8 = 185；第三片起点 2960 → 370。

🧮

原始数据报总长 4000（含首部 20），数据部分 3980 = 1480 + 1480 + 1020。最后一片不必是 8 的倍数。

📋 服务器还能塞给你这些

🛰️ 跨网段：DHCP 中继代理

广播不能过路由器。别的网段要有「中继代理」帮忙转发请求，DHCP 才能跨网段工作。

4.4.3 ICMP

ICMP：包裹送不到，至少给你个说法

NET / 13

😖 差错报告报文（5 种）

  • 终点不可达：目的地找不到
  • 源点抑制：我太忙了，你慢点发（已很少用）
  • 时间超过：TTL 减到 0，分组被丢
  • 参数问题：首部字段有错
  • 改变路由（重定向）：下次走另一个网关

🙅 不发送差错报文的几种情况

对 ICMP 差错报文不再发差错报文；
对非第一个分片不发；对多播地址不发；对特殊地址（127、0.0.0.0）不发。

🏓 ping 的原理

发送 回送请求（Echo Request），对方回 回送应答（Echo Reply）。测的是往返时间 RTT 和连通性。

🛰️ traceroute 的原理

从 TTL=1 开始逐次加 1。每经过一个路由器 TTL 减到 0，路由器回一个「时间超过」报文 —— 这样就把沿途每一跳的 IP 都套出来了。

📦

ICMP 报文装在 IP 数据报里发送，不是独立协议，协议号 = 1。

4.5 路由器

路由器：一个高速分拣中心

NET / 14

⚙️ 收到分组后发生什么

  • 物理层收比特 → 链路层拆帧
  • 检查目的 IP，查转发表
  • TTL 减 1，重算首部检验和
  • 重新封装成新帧，从对应端口发出去

转发

查表、搬数据，快

路由选择

跑协议、算路径，慢

🚦

输入端口如果来不及处理，会在缓存里排队；排满了就丢包 —— 这就是拥塞丢包。

4.6 路由选择

路由协议：全网路由器一起「对答案」

NET / 15
静态

手工配路由

管理员一条条写。简单、不耗 CPU，但网络一变就得重配。

适合：小网络、边缘路由器、默认路由

动态

协议自动算

路由器互相交换信息，自动算出转发表。能适应故障和拓扑变化。

适合：中大型网络、互联网主干

分层

AS 自治系统

把互联网切成很多个「自治区」，每个 AS 内部自己管，外部只交换可达性。

IGP 管内，EGP 管外

🗺️ 两大类路由协议

IGP

内部网关协议：在一个 AS 内部用，如 RIP、OSPF。目标是找最短/最快路径。

EGP

外部网关协议：AS 之间用，目前基本只有 BGP。目标是可达 + 策略，不是最短。

🎯 路由算法的两条路线

距离向量：只跟邻居聊天，交换「我到各处的距离」。代表 RIP。
链路状态：全网洪泛拓扑，自己算最短路。代表 OSPF。

4.6.2 RIP

RIP：只数「跳几次」，16 跳算迷路

NET / 16

📣 工作方式：和邻居唠嗑

  • 每个路由器只和相邻路由器交换信息
  • 交换的内容是整张距离向量表（到每个网络的距离）
  • 距离用跳数衡量，直连 = 1
  • 每 30 秒 广播一次，走 UDP 520 端口

📏 距离规则

最大跳数 15，16 表示不可达。
所以 RIP 只适合小型网络，直径不能超过 15 跳。

🐢

经典缺陷：「好消息传得快，坏消息传得慢」。一条链路断了，要很久才能传播到全网（计数到无穷问题）。

🔄 距离向量更新口诀

①

先把邻居表里所有距离 +1

②

下一跳改成那个邻居

③

和本表逐项比，更小就替换

④

30 秒没收到邻居更新 → 标记 16

🧠 一句话记住

RIP = 道听途说：我相信邻居说的距离，再加 1 传给别人。

算路

各自跑 Dijkstra，算最短路径树

✉️ 五种分组（背名字即可）

问候 Hello 数据库描述 链路状态请求 链路状态更新 链路状态确认

⚡ 比 RIP 强在哪

  • 收敛快，坏消息不会传半天
  • 支持负载均衡（多条等代价路径）
  • 支持区域划分，主干区域 0.0.0.0
  • 直接封装在 IP 里，协议号 89（不是 UDP）
  • 用代价（带宽、延迟）而不是跳数

🗺️ 为什么要分区域

网络太大，洪泛会压垮路由器。OSPF 把 AS 划成多个区域（Area），区域间只传汇总信息，主干区域固定为 0.0.0.0。

🧠

RIP 是「问邻居」，OSPF 是「自己拿地图导航」。一个靠传言，一个靠全局信息。

4.6.4 BGP

BGP：自治区之间的「外交谈判」

NET / 18

🌍 它解决什么问题

互联网有几十万个 AS。每个 AS 有自己的「政策」：谁能过、谁不能过、走哪便宜。
BGP 交换的不是「最短距离」，而是可达性 + 路径属性。

📌 关键点

  • 基于 TCP 179 端口，可靠传输
  • 交换的是路径向量：到某网络要经过哪些 AS
  • 用 AS 路径防环：看到自己的 AS 号就丢弃
  • 每个 AS 选一个 BGP 发言人

🆚 和内网协议的区别

维度RIP / OSPFBGP
范围AS 内部AS 之间
目标最短路径可达 + 策略
承载UDP / IPTCP 179
规模小 / 中全网
🤝

BGP 更像商务合作：不是「哪条路最近」，而是「跟谁合作更划算、更安全」。

4.8 NAT

NAT：全家共享一个门牌号

NET / 20

🏠 问题：IPv4 地址不够用

家里 5 台设备，只有 1 个公网 IP。怎么办？
NAT 让私有地址在出口路由器被换成公网地址，回来时再换回去。

🔁 NAPT：靠端口号区分

内网地址:端口→公网地址:端口
192.168.1.2:5000→203.0.113.5:61001
192.168.1.3:5000→203.0.113.5:61002

同一个公网 IP，用不同端口区分不同内网主机 —— 这就是 NAPT（端口多路复用）。

✅

NAT 缓解了 IPv4 地址枯竭，也隐藏了内网结构，但破坏了端到端透明性（外网不能主动连内网）。

🧠

考试常问：NAT 转换发生在哪一层？ —— 网络层（NAPT 还要看运输层端口）。

4.9 IPv6

IPv6：地址多到「给每粒沙子编号」

NET / 21

📏 128 位有多大

2¹²⁸ ≈ 3.4 × 10³⁸ 个地址。
IPv4 是 32 位，IPv6 是 128 位，多了 96 位。

✍️ 写法：冒号十六进制

2001:0db8:0000:0000:0000:ff00:0042:8329

零压缩后：
2001:db8::ff00:42:8329
连续的全 0 段可以用「::」代替，但只能出现一次。

📦 首部更简单

基本首部固定 40 字节；
取消首部检验和、取消分片字段（由源端做路径 MTU 发现）。

🆚 IPv4 vs IPv6

  • 翻译：NAT64 之类
4.7 / 4.8 拓展

VPN 与 MPLS：给数据报开条专用道

NET / 22
VPN

虚拟专用网

公司两个分部隔着公网，想安全通信。做法：把私有数据报加密后，塞进公网 IP 数据报里，走一条「隧道」。

  • 内层：私有地址，真正的收件人
  • 外层：公网地址，隧道两端

4.10 多播

多播：一份数据，发给一组人

NET / 23

📺 为什么需要多播

视频直播、网络会议：如果给 100 个人各发一份，服务器要复制 100 份。
多播只在分叉处复制，一条链路只传一份，省带宽。

🎯 多播地址

D 类地址 224.0.0.0 ~ 239.255.255.255
只用作目的地址，不能作源地址。它代表一个「组」，不是一个具体主机。

📡 IGMP

主机用它告诉本地多播路由器：「我要加入 / 退出这个组」。
IGMP 只在主机与本地路由器之间工作，不负责全网路由。

5.5 深入

中断判优、屏蔽与嵌套：谁能打断谁

IO / 07

🥇 判优：两个做法

  • 硬件排队器：电路固定优先级，快
  • 软件查询：按顺序查标志位，灵活但慢

优先级一般：故障 > DMA > 外设；高速设备优先于低速设备。

🙈 中断屏蔽字

每个中断源有一个屏蔽字：某位为 1，表示「我可以屏蔽掉它」。
修改屏蔽字，就能动态调整优先级。

📍 中断向量

每个中断源对应一个向量地址，里面存着中断服务程序的入口地址。CPU 识别中断源后，靠它跳过去。

🎚️

屏蔽不是「关掉设备」，而是「先别来打扰我」。

🪆 多重中断（中断嵌套）

高优先级中断可以打断低优先级的中断服务程序，形成嵌套。

主程序 → 中断 A → 中断 B（更急） → 返回 A → 返回主程序

🔑 实现嵌套的关键

进入中断服务程序后要提前开中断（STI），否则新中断进不来，就没法嵌套。

注意：保存现场必须在开中断之前完成，否则会被覆盖。

5.6 通道

通道：一台专门管 I/O 的小处理器

IO / 11

🧠 通道 vs DMA

DMA 一次只能管一台（或少数几台）设备的一次数据块传送；
通道能执行通道指令，一次控制多台设备，是「弱化的处理器」。

🗂️ 三种通道类型

  • 字节多路通道：多个低速设备，按字节交叉服务
  • 数组多路通道：多个高速设备，按数据块交叉服务
  • 选择通道：一次只服务一台高速设备，独占通道

📜 通道靠什么工作

执行通道指令（通道程序），指令放在主存里。CPU 只需在 FCB / CAW 中写清「从哪读、写到哪、多少字节」。

磁盘：算容量、算时间，都是送分题

IO / 12

💿 先认识几个词

盘面

每个盘片两个面

磁道

一圈同心圆

柱面

各盘面同号磁道组成

扇区

磁道再切成的弧段

📐 容量公式

容量 = 记录面数 × 磁道数/面 × 扇区数/道 × 扇区容量

磁盘地址 = 柱面号 + 磁头号 + 扇区号。寻道找柱面，选头定盘面，旋转等扇区。

🐢 为什么磁盘「慢」

寻道时间占大头，通常几毫秒；机械动作决定了它和内存差好几个数量级。这也是 SSD 存在的理由。

⏱️ 存取时间 = 三段时间之和

寻道

磁头移到目标磁道，最慢

旋转

等目标扇区转到磁头下，平均 半圈

传输

读出/写入数据本身

🔁 转速换算

7200 r/min = 120 r/s
平均旋转延迟 = 60 / (2 × 7200) ≈ 4.17 ms
转一圈 = 60 / 7200 ≈ 8.33 ms

手把手例题

转速 7200 转/分，传输率是多少？

IO / 13

题目

磁盘转速 7200 r/min，每个磁道 500 个扇区，每扇区 512 B。求：
① 平均旋转延迟　② 读一个扇区的时间　③ 数据传输率

① 平均旋转延迟

转一圈时间 = 60 ÷ 7200 = 8.33 ms
平均等半圈 = 8.33 ÷ 2 ≈ 4.17 ms

② 读一个扇区

8.33 ms ÷ 500 ≈ 0.0167 ms

③ 数据传输率

每秒转 120 圈，每圈 500 × 512 B：
120 × 500 × 512 B = 30 720 000 B/s
≈ 30.7 MB/s

也可以：512 B ÷ 0.0167 ms ≈ 30.7 MB/s，两种算法互相验证。

📝

答题模板：先写公式 → 代数字 → 带单位。平均旋转延迟一定用「半圈」，不是一整圈。

🧮

若题目给的是「平均寻道时间」，总存取时间 = 寻道 + 旋转 + 传输，三项相加。

输入输出系统 · 18 条速记

IO / 15
接口与中断
  • 接口功能：缓冲、检错、控制、译码、转换、中断
  • 统一编址用访存指令，独立编址用I/O 指令
  • 中断响应条件：有请求 + 开中断 + 指令结束
  • 响应过程：关中断、保存断点、识别中断源
  • 断点 = PC；现场 = 寄存器 + PSW
  • 中断服务最后：恢复现场、开中断、IRET
  • 多重中断要提前开中断
  • 屏蔽字可动态调整优先级
DMA、通道与磁盘
  • DMA 请求的是总线使用权，不破坏 CPU 现场
  • DMA 传送数据块，中断传送字节/字
  • DMA 优先级高于中断
  • DMA 三步：预处理 → 传送 → 后处理
  • 三种方式：停止 CPU、周期挪用、交替访问
  • 通道分：字节多路、数组多路、选择
  • 磁盘存取 = 寻道 + 旋转 + 传输
  • 平均旋转延迟 = 60 / (2 × 转速)
  • 容量 = 面数 × 道数 × 扇区数 × 扇区容量
