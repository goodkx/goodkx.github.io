# CCCAD 的数字小站

一套**零依赖、纯静态**的个人网站：博客、相册（20 幅手绘 SVG 含四季明信片）、14 件小工具、AI 工具导航、云留言板、
小卖部、四款小游戏（全站云排行榜）、考研大纲——全部手写 HTML/CSS/JS，无任何框架与外部依赖。
线上双托管：**GitHub Pages**（全球）+ **腾讯 EdgeOne Pages**（国内提速）。

## 快速个性化

| 要改什么 | 怎么改 |
|---|---|
| 名字 / 邮箱 / 社交链接 | 打开 `index.html`，按文件内注释搜索替换 |
| 自我介绍 / 技能 / 项目 | 找到 `<!-- 01 关于 -->`、`<!-- 02 技能 -->`、`<!-- 03 项目 -->` 区块 |
| 加新页面 | 1) 复制一个现有 html；2) 首页 `<!-- 05 页面导航 -->` 复制一张卡片；3) `search.js` 加一条索引 |
| 发博客 | `blog.html` 里 ① POSTS 加文章 ② 复制一张 `.post` 卡片 ③ `search.js` 加索引 ④ `feed.xml` 加条目 |
| 打字机角色词 | `script.js` 顶部 `roles = [...]` |
| 留言板站长口令 | `guestbook.html` 搜 `ADMIN_PASS`（默认 cccad2026，**务必修改**） |
| AI 工具清单 | `ai.html` 里按分类增删 `.ai-card` 卡片 |
