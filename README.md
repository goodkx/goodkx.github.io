# 个人网站 · 深色科技感首页

一套零依赖、纯静态的个人主页，双击 `index.html` 即可在浏览器打开。

## 文件结构

```
个人网站/
├── index.html   页面结构（内容都在这里改）
├── blog.html    博客页（文章列表，复制 post 块即可发文）
├── gallery.html 相册页（点击放大，SVG 占位图可换成 <img>）
├── tools.html   工具箱页（6 个纯前端小工具）
├── pelican.html 彩蛋页：鹈鹕骑自行车 SVG 动画
├── subpage.css  所有内页共用的基础样式
├── style.css    首页样式（配色、布局、动效）
├── script.js    首页交互（打字机、滚动动画等）
└── README.md    本说明
```

## 快速个性化（3 分钟）

打开 `index.html`，按文件顶部注释操作：

| 要改什么 | 怎么改 |
|---|---|
| 名字 | 全站搜索 `你的名字`，全部替换（5 处） |
| 邮箱 | 搜索 `hello@example.com` 替换（3 处） |
| 社交链接 | 搜索 `github.com/yourname`、`x.com/yourname` 换成你的主页 |
| 自我介绍 | 找到 `<!-- 01 关于 -->` 区块改文字 |
| 技能卡片 | 找到 `<!-- 02 技能 -->`，每张卡片复制/删除即可增减 |
| 项目 | 找到 `<!-- 03 项目 -->`，每个 `<article>` 是一个项目 |
| 经历时间线 | 找到 `<!-- 04 经历 -->` |
| **加一个新页面** | 1) 新建一个 html 文件（可复制 pelican.html 的框架）；2) 在首页找到 `<!-- 05 页面导航 -->`，复制一张 `<a class="page-card">` 卡片，改掉 href / 图标 / 文字 |
| 打字机角色词 | 打开 `script.js`，改顶部 `roles = [...]` 数组 |
| 终端窗口台词 | 打开 `script.js`，改 `termLines = [...]` 数组 |

## 换配色

打开 `style.css`，只改最上面 `:root` 里的几个颜色变量即可，例如换成赛博紫：

```css
--accent: #a78bfa;    /* 主色 */
--accent-2: #f472b6;  /* 辅色 */
```

## 免费上线

1. **GitHub Pages**：新建仓库 → 上传这些文件 → Settings → Pages → 选择分支，几分钟后得到 `https://你的用户名.github.io`。
2. **Vercel / Netlify**：注册后把文件夹直接拖进网页即可，一分钟拿到在线地址。

## 特性

- 响应式布局，手机 / 平板 / 电脑都适配
- 终端打字机、角色轮播、滚动显现、鼠标跟随光晕等动效
- 尊重系统「减弱动态效果」设置（prefers-reduced-motion）
- 无任何外部依赖，离线可用，加载飞快
